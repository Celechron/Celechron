# App Store Connect distribution

Archive the `Celechron` scheme in `Celechron.xcworkspace`. Its Release configuration
includes the iOS app, iOS widget, watchOS app, and watchOS widget.

Update the version/build in `pubspec.yaml` before preparing a new upload. Flutter
generates the version settings shared by all four bundles.

From the repository root:

```sh
flutter build ipa --release --flavor Celechron --export-options-plist=ios/ExportOptions.plist
```

Alternatively, use Xcode's Product > Archive and Organizer > Validate App >
Distribute App > App Store Connect. Keep the version/build numbers synchronized
across all four bundles.

Automatic signing selects the archive credentials and re-signs for distribution
during export. `ExportOptions.plist` selects App Store Connect, exports locally
without uploading, includes symbols, and preserves the configured build number.
The signed export requires an Apple Developer account with distribution signing
access and profiles for all four bundle IDs, including their App Group capability.

If command-line export reports missing distribution profiles, sign in to the
team in Xcode and let Organizer manage signing, or export the signed archive with:

```sh
xcodebuild -exportArchive \
  -archivePath build/ios/archive/Celechron.xcarchive \
  -exportPath build/ios/ipa \
  -exportOptionsPlist ios/ExportOptions.plist \
  -allowProvisioningUpdates
```

Release requests the production APNs entitlement; Debug and Profile request
development. Xcode derives the signed entitlements from the provisioning profile,
so an automatically signed archive may still carry development entitlements.
Verify the exported iOS app has `aps-environment = production` and no enabled
`get-task-allow` entitlement before upload.

`Shared/PrivacyInfo.xcprivacy` is copied into all four bundles and declares their
App Group UserDefaults access. Update it when first-party required-reason API
usage changes; dependency SDKs retain their own manifests.

The watch app's icon metadata is generated by Xcode from its AppIcon asset
catalog. Do not patch the built Info.plist or copy fallback icons into the bundle.

The shared Xcode scheme is named `Celechron`. For Flutter CLI commands, select
it with `--flavor Celechron` (for example, `flutter run --flavor Celechron`).
The workspace, project, app target, and source directory are named `Celechron`.
`ios/Runner` is a compatibility symlink to `Celechron` because Flutter still
uses that path for plugin registration and app delegate discovery.
